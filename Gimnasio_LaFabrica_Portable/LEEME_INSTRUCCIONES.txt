====================================================================
  GIMNASIO LA FÁBRICA - SISTEMA DESKTOP PORTABLE (SQLite3 + PDO)
====================================================================

¡Proyecto 100% Desacoplado de MySQL y XAMPP!
Ahora corre con un único archivo de base de datos embebido (database/gimnasio.sqlite)
y se ejecuta como una aplicación de escritorio nativa independiente.

--------------------------------------------------------------------
1. ¿CÓMO INICIAR EL SISTEMA EN WINDOWS?
--------------------------------------------------------------------
Tienes dos opciones de inicio:
   👉 iniciar_gimnasio.vbs  <- 100% Silencioso (Cero ventanas de consola)
   👉 iniciar_gimnasio.bat  <- Inicia el servidor en segundo plano y cierra la consola automáticamente

El script automáticamente:
  1. Detecta tu PHP (busca en \php\, PATH de Windows, o en C:\xampp\php\).
  2. Levanta el servidor local en segundo plano en http://127.0.0.1:8080.
  3. Abre la ventana de escritorio independiente en el Login.
  4. La consola de comandos se cierra automáticamente para evitar que el usuario la cierre por accidente.

Para apagar el sistema al finalizar la jornada:
   👉 Haz doble clic en: detener_gimnasio.bat

3. ¿QUÉ HACER SI NO TIENES PHP EN TU EQUIPO?
--------------------------------------------------------------------
Haz doble clic en:
   👉 descargar_php_portable.bat
Descargará e instalará automáticamente PHP portable oficial para Windows (25 MB)
dentro de la carpeta \php\ en 15 segundos.

--------------------------------------------------------------------
4. MÓDULOS Y NUEVAS FUNCIONALIDADES DESTACADAS
--------------------------------------------------------------------
- Visitas y Accesos (pages/visitas.php):
  * Check-in de socios con semáforo de vigencia.
  * Cobro de Visita Temporal / Pase Diario con campo para registrar el nombre del cliente y botón vinculado dinámicamente al precio del plan diario.

- Tienda y Ventas POS (pages/ventas.php):
  * Barra de búsqueda predictiva en tiempo real optimizada para catálogos de más de 300 clientes.
  * Soporte de compras "A Crédito / Deuda Pendiente" para fiar productos a los socios registrados.
  * Folios únicos autoincrementables con formato #0001 y desglose contable entre productos internos y externos.

- Gestión de Clientes (pages/clientes.php):
  * Botón "Info" en cada socio que abre la Ficha Completa con:
    1. Datos personales y contacto.
    2. Estado actual de membresía (Activo / Vencido) y días restantes.
    3. Historial de todas las membresías compradas.
    4. Estado de deudas con detalle de saldo atrasado y enlace directo a Abonos.
  * Alerta automática si el cliente cuenta con deuda atrasada al abrir el formulario de edición o al seleccionar renovar membresía.

- Módulo de Abonos y Deudas (pages/abonos.php):
  * Consulta centralizada de deudas pendientes y liquidadas.
  * Registro de abonos parciales o liquidación total con 1 solo clic.
  * Generación de comprobante imprimible de abono para el cliente.
